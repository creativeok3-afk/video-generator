# Shopee Video Generator 9:16 v3.0 (Impor Google Sheets + Voice Over)

Aplikasi web satu file (`index.html`) untuk membuat video promosi vertikal **9:16** siap unggah ke **Shopee Video**, **Instagram Reels**, dan **TikTok** langsung dari browser tanpa biaya langganan, tanpa server, dan tanpa *watermark*.

## Fitur Baru di v3.0
- **Impor Data Google Sheets (3 Cara Praktis):**
  1. **Copy-Paste Langsung (TSV):** Blok beberapa baris di Google Sheets Anda, tekan `Ctrl+C`, lalu tempel di aplikasi—semua produk otomatis masuk ke menu *dropdown*.
  2. **Upload File CSV:** Unduh Google Sheets sebagai `.csv` lalu muat ke aplikasi.
  3. **Link CSV Publik Google Sheets:** Tempel tautan *Publish to Web (CSV)* untuk menarik daftar produk secara instan.
- **Navigasi Produk Cepat:** Tombol **Sebelumnya / Berikutnya** serta *dropdown* produk yang otomatis mengisi *Nama Produk*, *Teks Hook*, *Label Harga/Promo*, *Naskah Voice Over*, hingga memuat foto jika tersedia URL gambar publik.
- **Voice Over Otomatis + Subtitle & Musik Latar Bawaan:** Lengkap dengan 3 pilihan *beat* musik bawaan dan *Safe-Zone overlay*.

## Cara Update di GitHub Pages
1. Buka repository GitHub Anda (`shopee-video-generator`).
2. Klik **Add file > Upload files**, unggah `index.html` terbaru ini untuk menggantikan file versi lama.
3. Klik **Commit changes** dan tunggu ±1 menit hingga halaman GitHub Pages Anda diperbarui.
