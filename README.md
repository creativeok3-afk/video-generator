# Shopee Video Generator 9:16 (Gratis & Offline)

Aplikasi web satu file (`index.html`) untuk membuat video promosi vertikal **9:16** siap unggah ke **Shopee Video**, **Instagram Reels**, dan **TikTok** langsung dari browser tanpa biaya langganan, tanpa server, dan tanpa *watermark*.

## Fitur Utama
- **100% Gratis & Client-Side:** Menggunakan HTML5 `<canvas>` dan `MediaRecorder API` bawaan browser.
- **Multi-Foto Produk (1–5 Gambar):** Otomatis memberi efek animasi *smooth zoom-in* per slide.
- **Safe-Zone Overlay:** Garis bantu area aman agar teks *hook*, harga promo, dan tombol ajakan tidak tertutup ikon kanan atau keranjang oranye di Shopee Video.
- **Pilihan Resolusi:** HD `720×1280` (ringan untuk laptop/HP standar) dan Full HD `1080×1920`.
- **Dukungan Audio Latar:** Bisa menambahkan file audio `.mp3` / `.wav` lokal.

## Cara Deploy ke GitHub Pages
1. Buat repository baru di GitHub (misalnya `shopee-video-generator`).
2. Upload file `index.html` dan `README.md` ke repository tersebut.
3. Buka menu **Settings > Pages**.
4. Pada bagian **Build and deployment > Source**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu ±1 menit, aplikasi siap diakses secara online lewat URL GitHub Pages Anda.
