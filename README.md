# Shopee Video Generator 9:16 v2.0 (Voice Over & Musik Bawaan)

Aplikasi web satu file (`index.html`) untuk membuat video promosi vertikal **9:16** siap unggah ke **Shopee Video**, **Instagram Reels**, dan **TikTok** langsung dari browser tanpa biaya langganan, tanpa server, dan tanpa *watermark*.

## Fitur Baru di v2.0
- **Voice Over Otomatis (Text-to-Speech):** Cukup tulis naskah promosi bahasa Indonesia, aplikasi otomatis membacakan narasinya sekaligus menampilkan **subtitle dinamis** di video.
- **Musik Latar Bawaan (Web Audio Synth):** Tersedia 3 pilihan *beat* musik latar langsung di aplikasi (*Shopee Promo Upbeat*, *Aesthetic Lo-Fi Santai*, dan *Flash Sale Cepat*) yang langsung terekam ke dalam file video tanpa perlu mengunggah MP3 eksternal.
- **Multi-Foto & Safe-Zone Overlay:** Animasi *smooth zoom-in* 1–5 foto produk dengan garis bantu agar elemen tidak tertutup ikon kanan atau keranjang oranye.

## Cara Update di GitHub Pages
1. Buka repository GitHub Anda (`shopee-video-generator`).
2. Klik file `index.html` > klik ikon pensil (**Edit this file**) atau pilih **Add file > Upload files** untuk menimpa `index.html` versi lama.
3. Klik **Commit changes** dan tunggu ±1 menit hingga GitHub Pages diperbarui.
